Menos de 5 segundos por documento. Cache automático por hash; si pediste lo mismo antes la segunda vez es instantánea.

Estructurado

Schemas predefinidos para invoice, CV y receipt. El JSON viene validado, sin que tengas que parsear nada.

Simple

API REST con bearer auth. Una llamada, un JSON. Lo mismo desde Python, Node, Go o curl.

Una sola llamada

curl -X POST https://api.parsero.dev/api/v1/extract \
  -H "Authorization: Bearer psr_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "document_url": "https://example.com/factura.pdf",
    "schema_type": "invoice"
  }'
