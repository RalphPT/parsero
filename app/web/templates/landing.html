Privacidad y seguridad

Lo que hacemos (y no hacemos) con tus datos.

¿Guardan mis documentos? +

No guardamos el PDF. Solo persistimos el hash SHA-256 (para el cache), el JSON extraído y los tokens consumidos. El binario del documento se procesa en memoria y se descarta.

¿Qué LLM usan por debajo? +

Gemini 2.5 Flash de Google. El texto extraído del PDF viaja a la API de Google según su política de privacidad. Si tu caso requiere un proveedor específico (Claude, modelo on-prem), escríbenos.

¿Dónde está hosteado? +

Railway en región US-West. Postgres y Redis también están en Railway, en la misma región. Si necesitas data residency en EU o LATAM, escríbenos para coordinar.

¿Cómo protegen mis API keys? +

Hasheamos cada key con SHA-256 al crearla. La key en claro se muestra una vez en el dashboard y nunca más. Aunque alguien acceda a la BD, no puede recuperar las keys originales. Puedes revocar y rotar cuando quieras.

¿Son GDPR / SOC2 compliant? +

Por ahora no formalmente, somos v0.1. Si tu caso de uso requiere certificación, escríbenos a hola@parsero.dev y armamos un plan a medida (DPA, región específica, etc.).

¿El código es open source? +

Sí. github.com/RalphPT/parsero. Puedes auditar cómo manejamos auth, rate limiting y persistencia. Si encuentras algo, abre un issue o escríbenos.
